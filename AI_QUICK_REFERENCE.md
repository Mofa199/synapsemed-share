## 💡 4 AI Services

### 1. Ask Questions 🔵
- **What**: Get detailed medical answers
- **Input**: Any medical question
- **Output**: Answer + sources + confidence score
- **Example**: "What is hypertension?"

### 2. Generate Flashcards 🟢
- **What**: Create study cards
- **Input**: Topic name
- **Output**: 5-10 flashcards with front/back/hint
- **Example**: "Cardiovascular System"

### 3. Create Exam Questions 🟣
- **What**: Practice test questions
- **Input**: Topic + number of questions
- **Output**: Multiple choice with explanations
- **Example**: "Diabetes Management" → 5 questions

### 4. Get Recommendations 🟡
- **What**: Personalized study tips
- **Input**: (Automatic - uses your context)
- **Output**: Priority-based advice + resources
- **Example**: High-priority topics to focus on

## 🔧 Troubleshooting

### AI Button Not Showing?
- ✅ Make sure you're logged in
- ✅ Refresh the page
- ✅ Check if backend is running (port 8000)

### No AI Response?
- ✅ Check AI backend: http://localhost:8000/health
- ✅ Should return: `{"status": "healthy"}`
- ✅ Restart if needed: `venv\Scripts\python.exe main_simple.py`

### TypeScript Errors?
- ⚠️ Type errors won't affect runtime
- ✅ App will still work normally
- ℹ️ Can be ignored for now
